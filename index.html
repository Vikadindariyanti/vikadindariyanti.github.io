About Me

Halo, saya Vika Adinda Ariyanti, siswi SMK Negeri 5 Malang yang memiliki ketertarikan di bidang pengembangan web. Saya senang mempelajari teknologi dan terus mengasah kemampuan melalui berbagai proyek serta tugas sekolah. Saya telah mengerjakan beberapa proyek menggunakan HTML, CSS, Bootstrap, PHP, dan MySQL, seperti website portofolio dan aplikasi sederhana berbasis database.

Melalui setiap proyek yang saya kerjakan, saya belajar mengenai pembuatan antarmuka, pengelolaan data, serta pentingnya ketelitian dalam proses pengembangan aplikasi. Saya juga memiliki kemampuan bekerja secara individu maupun dalam tim, mudah beradaptasi, dan selalu berusaha menyelesaikan setiap tugas dengan baik. Ke depannya, saya ingin terus mengembangkan kemampuan di bidang web development dan mempersiapkan diri untuk menjadi seorang web developer.
